- **Attacker Persona:** `The SQL Injector`
- **Target Response:** HTTP `500`
- **Attack Hypothesis:** *"Unsanitized coupon_code concatenated into raw SQL string will trigger OperationalError."*

#### 💣 Reproducing Payload
```json

  "username": "shopper_sqli",
  "quantity": 1,
  "coupon_code": "' OR 1=1 --",
  "shipping_note": "Deliver to front desk",
  "metadata": {
    "source": "fuzzer"
  }
}
```

#### 🔍 Root Cause Analysis
> Unsanitized user-controlled coupon_code is concatenated directly into raw SQL query strings, allowing attackers to manipulate query structure.

