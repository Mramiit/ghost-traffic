================================================================================
DUAL-STAGE AGENTIC HARNESS OVERVIEW
================================================================================

Ghost Traffic leverages the BharatCode `qwen-3.8-27b` intelligence engine in a
coordinated dual-stage agentic pipeline designed to autonomously stress-test,
fuzz, and heal modern REST and microservice APIs:

--------------------------------------------------------------------------------
STAGE 1: PERSONA-DRIVEN ADVERSARIAL PAYLOAD SYNTHESIS
--------------------------------------------------------------------------------
Traditional fuzzing relies on random bit mutations or brute-force dictionaries,
failing to test complex business logic and semantic constraints. Ghost Traffic
uses the BharatCode API to act as a Principal Security & Chaos QA Engineer that:
1. Ingests raw OpenAPI 3.0 / JSON Schemas to map expected types, boundaries,
   and business relationships.
2. Summons 5 specialized "Chaos Personas" to generate surgical payloads:
   - "The SQL Injector": Injects stacked queries, comment truncations, and
     unparameterized SQL bypasses into text fields.
   - "The Unicode Destroyer": Synthesizes 4-byte UTF-8 emojis, Zero-Width
     Joiners (\u200d), and RTL overrides to crash legacy database drivers.
   - "The Boundary Pusher": Tests numeric zero divisions, negative reserves,
     and integer underflow boundaries.
   - "The Type Anarchist": Delivers type-confusion mutations (e.g., passing
     arrays/integers where strings are expected to trigger unhandled .upper()).
   - "The Nesting Fiend": Injects deep object nesting (> 5 levels) to trigger
     stack exhaustion and RecursionErrors.
3. Formats payloads into strict structured JSON with explicit hypotheses.

--------------------------------------------------------------------------------
STAGE 2: STACK-TRACE ROOT-CAUSE TRIAGE & PATCH GENERATION
--------------------------------------------------------------------------------
When the async HTTPX fuzzing swarm triggers an unhandled HTTP 500 crash or
traceback on the target system:
1. Ghost Traffic intercepts the runtime error class, exception detail, and
   raw Python traceback.
2. The BharatCode API evaluates the crash context against the offending payload
   to perform automated Root Cause Analysis (RCA):
   - Maps the vulnerability to standardized Common Weakness Enumeration
     taxonomy (e.g., CWE-89, CWE-369, CWE-176, CWE-674, CWE-843).
   - Assigns a severity score (CRITICAL, HIGH, MEDIUM).
   - Produces a 1-sentence technical explanation of why the backend failed.
3. Generates a concise, surgical 2-4 line Python code patch (`fix_diff`) that
   developers can immediately apply to harden the endpoint.
4. Compiles the findings into an executive Markdown security audit report
   (`GHOST_REPORT.md`) ready to attach to GitHub Issues or Pull Requests.
